# 小鲸哨 2.1.1 · 验收记录

## 本轮范围

2.1.1 修复 2.1.0 暴露的两个显示问题，并保留 2.0 / 2.1.0 的全部能力：

1. **等待卡配色**：等待中的任务卡原来固定使用浅奶油底 `#FFFBF0`，而文字已改为主题 token；深色主题下变成浅底浅字。现在改为「宿主表面色 88% + 宿主警告色 12%」的混合，深色是深橄榄底、浅色是暖奶油底，文字始终跟随主题。
2. **进行中不再重复出现在最近动态**：同一个会话的 `开始` / `等待` 事件本来由上方活动行表达，历史区再列一次会像重复任务。现在只过滤「该会话仍在活动且事件是 running/waiting」的行，结束结果（完成/异常/停止）仍然保留。
3. 版本推进到 2.1.1；其余为 2.1.0 已交付能力（工作区与子任务聚合、多窗口 presence、长任务提醒、导航诊断、DSH 主题 token、客户端拆分与体积优化、发布与构建门禁）。

未修改 DSH 核心或安装包。

本轮新增门禁：

- 活动会话的 running/waiting 事件不得再出现在历史行；结束结果必须保留；
- 气泡仍对真实等待事件作出反应（过滤只影响列表，不影响提醒）；
- 行元素暴露 `data-session`，便于真机核对是否重复。

- **未在真实运行的两个 DSH 实例间点通知**：双实例做到注册表与启动器级实测。
