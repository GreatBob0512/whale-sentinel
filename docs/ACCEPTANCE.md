# 小鲸哨 2.3.0 · 验收记录

## 本轮范围

2.3.0 把“提醒的边界”和“打开就稳”一次做完：

1. **一条前台规则**：页面在前台且未开启“前台也通知”时，客户端调用宿主 `suppress` 撤回待发通知；不再出现“页面不弹、宿主 10 秒后补弹”。页面与原生两条通道共用同一判断。
2. **完成合并**：同一轮到期的多个 `done` 只发一条原生通知，正文追加“另有 N 个任务已完成”，其余标记 `aggregated` 留在面板。
3. **结果独立记录**：终态事件写入独立 `results`（上限 50），不再从混合事件里现筛；启动事件再多也不会把结果挤掉。
4. **默认标签只定一次**：打开面板时按当时数据选一次，数据随后到达不跳栏；方向键 / Home / End 可切换，tab 与 tabpanel 具备正确标签关系。
5. **陈旧提示**：断线时显示“离线 · 上次同步 X”，不再把最后状态当实时。
6. **徽章即入口**：隐藏角色后保留的徽章可以直接打开面板，角色仍可在设置里恢复。
7. **上一轮标记**：会话已开始新一轮时，它的旧结果标“上一轮”。

未修改 DSH 核心或安装包。

- **浅色未切换实测**；**520px 以下未实测**；**真实横幅点击**与**双实例点击**仍未验证。
- 真机抓取时“结果”为 0，因此结果卡片、`×n` 与“上一轮”只做了单元验证。
- 以上未做项不得表述为“已验收通过”。
