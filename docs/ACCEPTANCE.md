# 小鲸哨 2.2.0 · 验收记录

## 本轮范围

2.2.0 把顶部三颗“统计胶囊”改成真正的互斥标签页，并把结果按会话归档：

1. **待处理 / 进行中 / 结果** 三个标签互斥：等待中的会话只算“待处理”，不再同时出现在“进行中”；每个标签显示自己的数量与自己的行。
2. 默认落在最需要你的一类：有待处理 → 待处理；否则进行中；都没有 → 结果。显式选中后即使该类为空也保留，并显示自己的空态，不自动跳走。
3. **结果按会话归档**：同一会话的多次结束记录合并为一行，右上角 `×n` 标出保留次数；默认 5 条，可展开；超过 20 个已结束会话时提示“只保留最近 50 条结束记录”。
4. 结果行不再包含 `开始/等待` 这类临时事件（它们只是活动标签的另一种表达），因此不会出现“同一任务上下各一份”。

未修改 DSH 核心或安装包。

本轮新增门禁：

- 顶部必须是 `role=tablist` / `role=tab` 的真实标签，选中态可见；
- 等待与运行按 `waiting` 互斥分桶，等待会话不得计入运行中；
- 结果按 `sessionId` 合并，默认 5 条，保留窗口有说明；
- 三个标签的计数分别等于各自桶的大小；
- 选中的空标签显示自己的空态，而不是另一个标签的内容；
- 结果只来自终态事件，`running/waiting` 永不进入结果行；
- 2.1.1 的等待卡主题色、活动会话不重复、主题对比度等门禁继续保留。
