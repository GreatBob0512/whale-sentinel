# 鲸哨 · 轻量任务雷达

**看进展，收提醒，点一下回到对应会话。**

面板位于角色左侧、角色贴右下角；两者并排，不互相遮挡。鲸哨是 DeepSeek Harness（DSH）的非官方任务提醒插件。当前版本 1.8.8 的看板娘有两种姿态：**收起时坐在工位前办公**（五种任务状态对应五种坐姿与屏幕内容），**展开看板后站到看板旁、一手扶着边框、一手指向任务**。角色提示进行中、待回应和结果，面板读取真实会话事实；不提供年龄阶段切换或换装。

### 后端系统通知

![Windows 通知样式：应用名、任务标题、结果摘要与关闭按钮；设计示意](<docs/notification-preview.png>)

*通知样式的设计示意，**不是真实系统截图**。实际通知由插件生成：左侧是当前状态的角色图标，标题与正文来自真实结束原因和结果摘要，点击卡片回到对应会话。*

系统通知与页面内提示是两条独立通道：原生通知由 Windows 弹出，受通知权限、勿扰和横幅设置影响；「前台也通知」关闭时，正看着 DSH 会延后原生弹出，避免重复打扰。

## 查看进展与结果

| 看哪里 | 表示什么 |
| --- | --- |
| 角色动作与屏幕 | 收起时：待命挥手、进行中打字、等待举手、完成伸懒腰、异常排查；展开后：同一角色站起抓着面板边框指向任务 |
| 角色微动画 | 整身轻微上下浮动，指向看板的手指处有脉冲光环；动画只是提示，不增加信息含义 |
| 姿态切换 | 点开面板即换成指向姿态，关闭恢复坐姿；两者使用同一套画风与配色 |
| 角色右上红点 | 存在需要你处理的会话，最多显示 3 颗；完整数量在面板中查看 |
| 进行中条目 | 会话阶段、当前工具、步骤与运行时长 |
| 进度条与 `2/5` | 真实待办中完成 2 条、总计 5 条；不是剩余用时或工作量估计 |
| 最近动态 | 完成、手动停止、异常等真实结束结果与短摘要；默认显示 3 条，可展开查看更多 |
| 连接提示 | 断线时保留最后状态，并明确提示非实时 |

- **点击角色打开面板**。顶部只列出当前仍在运行或等待处理的会话，**不按最近几小时过滤**；等待处理的排前面，其余按最近活动排序。会话结束或代理释放后离开顶部，事件进入最近动态。任务和结果条目均可点击，返回原会话查看完整内容。
- **最近动态默认显示最近 3 条**，通过「查看更多结果」展开其余记录；面板限高并内部滚动。
- 有真实待办才显示进度；没有待办时只显示阶段、步骤或工具活动，不制造完成百分比。
- 「完成」来自真实结束原因；**手动停止、异常、静默和窗口空闲都不等于成功**。
- 等待批准、选择或文字输入分别提示；请回原会话处理。回答后旧的页面待答通知会撤回。

## 返回对应会话

| 入口 | 处理方式 | 需要注意 |
| --- | --- | --- |
| 面板中的任务／结果 | 按条目的会话标识请求导航 | 完整答案、文件和错误记录仍在原会话 |
| 角色旁提醒气泡 | 点击气泡正文返回该提醒对应的会话；× 只关闭气泡 | 气泡不代答、不批准任何操作 |
| 页面系统通知 | 点击携带的会话标识，并尝试唤起原 DSH 窗口 | 窗口唤起受 Windows 前台限制 |
| Windows 原生备用通知 | 插件自有协议携带一次性短期标识，由后台绑定回对应会话 | 依赖当前宿主与页面仍运行；插件重启、退出或标识过期后旧通知可能失效 |

**Windows 窗口唤起会尝试还原、最大化并置前**，不是 F11 无边全屏。点击备用通知的协议入口使用 `wscript.exe` 隐藏启动本地处理脚本，避免直接启动控制台程序造成终端闪窗；这不等于安装一个新的 DSH 实例。

## 提醒如何工作

![真实事件经宿主投影进入面板，再到页面／原生通知与对应会话；概念示意，非运行截图](<docs/session-flow.png>)

*通知与导航流程示意。显示回调、原生提交、导航请求和用户实际阅读分别记录，不能互相代替。*

- **页面主通道**：按通知事件认领；只有系统 `onshow` 回调才记录为显示回调，构造通知对象不算显示成功。
- **宿主备用通道**：页面没有权限、发送失败或无回执时，尝试 Windows 原生通知。
- **前台去重**：后台原生备用通知会参考页面是否可见且聚焦，避免在用户正看着 DSH 时重复提醒；这条去重只作用于原生 backend 通道。失焦、最小化、页面挂起和心跳时效分别处理，不把旧心跳当作永久前台。
- **系统限制**：Windows 权限、勿扰、横幅设置和窗口前台规则都可能影响效果。原生「已提交」不代表横幅已显示，更不代表用户已读。
- 多通道优先减少漏提醒，但不承诺跨页面与系统的绝对“只显示一次”；页面冻结后恢复、系统延迟时仍可能短暂重复。

**不修改 DSH 核心或安装包，不覆盖 `app.asar`。** Windows 点击定位只在当前用户下注册插件自己的 `dsh-whale-*` 协议，调用固定本地脚本；正常禁用／卸载时清理自己的注册。异常强制退出可能留下自有协议，旧通知不应据此猜测或跳到最近会话。无需管理员权限、服务或计划任务。

## 外观与提醒

![隐藏角色、气泡静音、系统通知、提示音和音量各自独立；操作示意，非运行截图](<docs/controls-guide.png>)

*点击面板齿轮打开设置；图标按钮有名称提示和无障碍标签。*

| 控制 | 影响范围 |
| --- | --- |
| 隐藏角色 | 只收起立绘；**界面内提示气泡仍会出现**，右下角保留恢复钮；不停止会话、不顺带关闭通知或音效 |
| 静音气泡 | 不显示角色旁文字气泡；不等于全局静音 |
| 系统通知 | 控制系统提醒，设置由后台保存；不关闭页面内独立提示音 |
| 柔和音效 | 默认关闭；开启后按新结果／待答事件尝试播放本地短音，1 秒节流 |
| 试听与音量 | 试听可通过用户交互解锁音频；滑块只调页面 WebAudio，Windows 备用系统提示音仍由系统音量管理 |
| 收起尺寸 | 80%–160% 滑块，旁边显示百分比；只影响收起时的坐姿角色 |
| 展开尺寸 | 80%–160% 滑块，旁边显示百分比；只影响展开时指向看板的角色，两个尺寸互不影响 |
| 前台也通知 | 默认关闭：正看着 DSH 时后台备用通知延后。开启后即使窗口可见且聚焦也发系统通知 |

音效不读取麦克风、不调用远程语音合成。浏览器阻止播放或页面挂起时，音效可能不响，不能因此判定通知或任务失败。

角色动画遵守系统的「减少动态效果」偏好；开启后浮动、摆动与脉冲会停止。动画不改变任务状态，也不代表真实进度。

## 遇到问题

| 现象 | 先检查 |
| --- | --- |
| 原生显示「已提交」但无横幅 | Windows 通知权限、勿扰、横幅和通知中心；提交不证明已显示 |
| 点旧通知没有回会话 | 是否属于插件重启前、已退出应用或已过期的通知；用新通知验证 |
| DSH 最小化后没有唤起 | 查看实际窗口恢复诊断；同一程序存在不可区分窗口时可能拒绝任意选择 |
| 列表仍在但提示连接中断 | 列表是最后已知状态；回原会话检查，不能据此判定任务仍在运行 |
| 关了气泡仍有声音 | 检查柔和音效与 Windows 系统通知声音，它们独立于气泡 |
| 开了音效却无声音 | 先点一次试听，检查开关、音量、节流和页面是否被挂起 |
| 完全退出 DSH 后无提醒 | 缩到托盘与真正退出不同；后台宿主退出后无法继续跟踪或提醒 |
