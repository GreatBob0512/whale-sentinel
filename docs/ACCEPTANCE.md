# 鲸哨 1.8.8 · 验收记录

## 本轮范围

当前版本有**两套运行素材**：看板收起时显示坐在工位前办公的角色，展开时换成站在看板旁、抓住边框并指向任务的角色；收起再切回。形象仍沿用用户指定的 `outputs/whale-relock/mini-three-views.png` 基准，只含幼年一种形态，无年龄切换或换装。提醒链路、协议与偏好逻辑未改，未修改 DSH 核心或安装包。

- 两套姿势图都以该角色为参考、用 `gpt-image-2.6` 生成，纯白背景（透明底生成会出现边缘噪点）。
- 白底由本地脚本 flood fill 抠除，再按 alpha 连通域拆帧，不按固定列宽切割，避免裁断头发或鲸尾。
- 展开态使用紧凑裁剪，去掉透明留白，避免图片元素比人物更宽导致显示过大、贴不近边框。

## 素材清单一致性

[artwork.json](<../assets/artwork.json>) 记录两套素材：

- 坐姿：`id` 为 `whale-it-seated-v1`，`approvedSource` 指向用户指定的角色基准三视图，`poseSheet` 记录姿势图及其 SHA-256；五态条目记录拆帧来源与每个文件的哈希。
- 展开态：`buddy` 字段记录 `format: webp`、`crop: tight bounds`、`sheet` 与哈希、每个状态的尺寸与哈希。

规格：坐姿页面立绘 384×576、通知图标 128×128、原生侧图 160×192、插件图标 256×256 透明整身；展开态 WebP 224×462，五张合计约 134 KB。内联数据与磁盘文件逐字节相同。

## 尺寸设置

设置面板提供提示音音量、**收起尺寸**、**展开尺寸**三个滑块；两个尺寸滑块各自 80%–160%、互相独立、分别持久化。收起尺寸作用于 `--dpg-scale`，展开尺寸作用于 `--dpg-buddy-scale` 乘以像素基准 `--dpg-buddy-h`。

## 自动化

`node check.mjs` → **128 tests / 128 pass / 0 fail**，除回归外还包含素材门禁：

- 每帧必须是不同姿势，不能是同一张复制品；
- 页面 DOM 素材标识必须等于清单 ID；
- 展开态必须是 WebP、必须是紧凑裁剪，且分辨率足以在显示缩放时保持清晰；
- 内联数据与发布文件逐字节一致；
- 两个尺寸设置各自独立、越界值被夹紧、非法类型被拒绝。
