# 鲸哨 2.3.1 · 素材说明

**当前版本只用幼年形态「小鲸哨」，不提供年龄切换或换装。** 她有**两套运行素材**：看板收起时坐在工位前办公，看板展开时站到看板旁、一手抓住边框、一手指向任务。本文不把历史探索图或生成过程当成用户验收。

![鲸哨五态整身素材手册；素材图解，非运行截图](<state-handbook.png>)

## 角色基准

角色形象以用户指定的工作区 `outputs/whale-relock/mini-three-views.png` 为唯一基准。所有姿势都用 `gpt-image-2.6` 以该角色为参考图生图生成，再在本地完成抠图、拆帧与尺寸统一。

该源图是 1536 × 1024 白底三视图设定稿，本身不是透明运行素材。

| 维度 | 基准 |
| --- | --- |
| 脸与神态 | 幼年圆脸、大蓝眼、纯可爱笑容、一颗小虎牙 |
| 头发 | 深藏青长发与浅蓝发尾，自然宽缓波浪 |
| 头饰 | 白蕾丝女仆头箍、侧面小鲸鱼发夹与白色发卡、深蓝白蕾丝布料侧翼 |
| 衣装 | 完整覆盖的深蓝童装女仆裙，短泡泡袖，白门襟与完整白围裙小鲸鱼；胸前、腰部、袖口均为薄荷绿蝴蝶结 |
| 裙袜与其余识别 | 白蕾丝袜、薄荷绿鞋蝴蝶结、深蓝鞋、浅蓝鲸尾；展示完整整身 |

形象保持纯可爱、非性化：不采用露肩低领、成人身体曲线或薄纱礼装。

## 收起态：坐姿工位五态

五态统一为**坐在工位前办公**：一张小巧的浅灰蓝办公桌与一台小一体机，五格桌面高度一致，屏幕内容随任务状态变化。

| 状态 | 角色动作 | 屏幕内容 |
| --- | --- | --- |
| 待命 | 坐在桌前挥手打招呼 | 鲸鱼图标 |
| 进行中 | 身体前倾、双手在键盘上打字 | 多行代码 |
| 等待回应 | 一手举起、一手托腮看着用户 | 对话气泡 |
| 完成 | 坐在椅子上双手高举伸懒腰 | 绿色对勾 |
| 异常 | 从桌下探身、手持小螺丝刀 | 警告图标 |

屏幕内容只是状态提示的视觉补充，面板文字与进度仍以真实会话事实为准。

## 展开态角色素材

点开看板后，底部坐姿角色换成**站在看板旁、抓住边框并指向任务**的姿态；收起再切回坐姿。

| 项目 | 说明 |
| --- | --- |
| 姿势图 | 工作区 `outputs/whale-buddy/buddy-five-white.png`，白底五格横排 |
| 五表情 | 平静微笑、专注、惊讶期待、开心大笑、为难 |
| 统一手势 | 右手握拳做出抓住竖直边缘的动作，左手食指指向左侧（即看板方向） |
| 切帧 | `outputs/whale-buddy/split-buddy2.py`：白底 flood fill → alpha 连通域拆帧 → **紧凑裁剪** |
| 打包 | `whale-sentinel/scripts/build-buddy2.py`：转 WebP 并写入客户端内联 |
| 规格 | WebP，224 × 462，quality 58，五张合计约 134 KB |
| 动画 | 整身轻微上下浮动 + 指向处脉冲光环 |

**为何用紧凑裁剪**：切帧若把人物居中放进固定画布，图片元素就会比人物本身更宽。透明留白虽然看不见，却会撑大渲染尺寸，让人物显得过大、也与看板边框贴不近。按 alpha 边界紧凑裁剪后，图片左边缘就是人物左边缘，CSS 的负边距才能真正让指尖压住边框。

**为何用 WebP 并内联**：WebP 在同等清晰度下体积远小于 PNG，五个状态才放得进客户端的体积预算；内联则避免依赖额外的静态资源路由，页面加载即用。

**动画边界**：展开态只做整身浮动与指尖脉冲。曾经尝试用「同一张图裁出头部再单独旋转」做面部动画，但裁剪边缘在旋转时会暴露成轮廓撕裂（头部看起来裂开），该做法已删除。真正的眨眼需要为每个状态额外准备闭眼帧，目前**没有做**。

## 从姿势图到运行素材

```text
角色形象基准 · mini-three-views.png
        ↓ 以该角色为参考图生图（纯白背景）
五态姿势图
        ↓ 本地抠白底、按透明连通域拆帧
五张独立整身姿势
        ↓ 统一缩放、留安全边距（坐姿）／紧凑裁剪（展开态）
页面立绘 + 系统通知图标 + 原生通知侧图 + 插件图标 + 展开态 WebP
```

- 生图使用纯白背景，避免透明背景生成时出现的边缘噪点；白底由本地脚本抠除。
- 拆帧按 alpha 连通域处理，不按固定列宽切割，避免裁断头发或鲸尾。
- 坐姿运行素材：五张页面立绘各 **288 × 432**（按最大 160% 显示仍有 1.5 倍以上余量，用于压低内联体积）；通知图标各 **128 × 128**；原生通知侧图各 **160 × 192**；插件图标 **256 × 256 透明整身图**，SVG 包装与 PNG 同步。
- 展开态素材：五张 WebP 各 **224 × 462**，内联进客户端。
- [素材清单](<../assets/artwork.json>)记录坐姿前缀的状态条目，以及 `buddy` 字段下的展开态来源、尺寸、哈希与字节。
- 页面使用打包内联素材。仅替换磁盘文件不足以证明实际页面已更新；页面、通知与图标应分别核实。
- 说明手册由当前素材排版生成，**不是运行截图**。透明边缘与小尺寸效果仍需单独检查。
- 没有年龄阶段切换或换装入口。

## 尺寸设置

设置面板有三个滑块：提示音音量、**收起尺寸**、**展开尺寸**。两个尺寸滑块各自 80%–160%、互相独立、分别持久化：

- 收起尺寸走 CSS 变量 `--dpg-scale`，作用于坐姿立绘的基础尺寸。
- 展开尺寸走 `--dpg-buddy-scale`，乘以像素基准 `--dpg-buddy-h`（236px）。
- 展开态默认约占面板宽度的 38%，左边缘压进面板边框 10px。
